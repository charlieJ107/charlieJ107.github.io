## Sign up and enter the service

Open [AI.Zhuoling.Space](https://ai.zhuoling.space), register and sign in. Registration is open, and the service is available after signing up. Consult the application for current model availability, tools and usage information.

## Create an Avatar

Open the Avatar area and create an Avatar. Give it a name and identity: who it is, how you would like it to interact with you, and what background it should understand over time. The form offers guided and expert modes; start with guided configuration and refine it as you go.

For example, you could configure an Avatar to help organize personal projects, describing the project background and your preferred communication style. This example illustrates a way to approach the configuration.

## Configure a Persona

Creating an Avatar also creates its default Persona. Open Persona management to configure its name, prompt, preferred model, available skills and tools. An Avatar can have multiple Personas for situations such as writing discussions and technical collaboration.

The Avatar provides a persistent identity; the Persona defines the voice and capabilities for an interaction. Keep a default Persona to make subsequent sessions easy to start.

## Begin a session

From the Avatar's session entry, choose a Persona and model, then send your first message. Start with a concrete task, such as “Help me turn this project idea into a list of questions.” Tools that need additional information can request input within the conversation and continue after you submit an answer.

The current version selects a Persona when creating a session. To try another Persona, return to the session entry and create a new session. Existing sessions remain accessible through the history list.

## Understand the role of memory

The context layer retrieves relevant memories for that Avatar using the current message. With the corresponding tools enabled, the model can also search, write or update memories. Retrieval depends on existing records, the query and model configuration. Provide or correct facts directly in the current conversation when you need an accurate basis for a task.

Continue with [context and memory](/projects/ai-avatar/docs/context-and-memory/) to see how these inputs fit together.
