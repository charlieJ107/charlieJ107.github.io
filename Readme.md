# charlieJ107.github.io

Charlie的个人网站内容仓库。网站在 **[zhuoling.space](https://zhuoling.space)**，这里保存网站上已发布的博客、简历、项目与服务介绍的 Markdown 原文及其配图，同时承担 `charliej107.github.io` 的跳转。

Personal website content of Charlie. The site lives at **[zhuoling.space](https://zhuoling.space)**. This repository holds the published Markdown behind it, and redirects the `charliej107.github.io` address.

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `blog/en/`、`blog/zh/` | 博客文章 |
| `cv/en/`、`cv/zh/` | 简历条目，按类别组织 |
| `projects/en/`、`projects/zh/` | 个人项目介绍 |
| `service/`、`about/` | 服务说明与关于页面 |
| `images/` | 文章与页面配图 |
| `.legacy-pages/` | 旧网址跳转页面，由构建流程生成 |

每篇内容都是带 YAML frontmatter 的 Markdown，可以直接阅读，也便于引用和检索。文章的公开 URL 由文件名决定。
